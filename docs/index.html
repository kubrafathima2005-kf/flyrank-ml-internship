Content Review Prioritization Using Machine Learning

An experimental study using anonymized content metadata

Research by Kubra Fathima

Question Data Methodology Results Limitations Recommendations

Abstract

This study explores how machine learning can support FlyRank's content refresh workflow by helping editors identify pages that may need attention. Using an anonymized dataset of 30,000 content records, a Random Forest model was trained and evaluated against a rule-based baseline. The baseline achieved a Precision@50 of 0.46, while the Random Forest achieved 0.40. The results show that the baseline performed better in this experiment. Therefore, the model is presented as an experimental decision-support tool for human review, not an automatic decision-making system.

1. Introduction and Research Question

FlyRank works with content performance and content refresh workflows. Editors need to identify which pages may require attention, so they can review them in a useful order.

This project explores whether machine learning can help prioritize content pages for editorial review using content and keyword metadata.

The research question is: Can machine learning help identify content pages that may need attention?

The system provides review suggestions only. Human editors make the final decisions, and no content is changed automatically.

One row represents one anonymized content page. The development and verification work used the March 2026 window where specified in the data-contract analysis.

Features include search volume, competition, CPC, word count, character count, content type, main intent and competition level.

Identifiers were not used as model features. Target-related fields and historical performance fields that could reveal the outcome were excluded from the final model. No client names, private URLs or private search queries are published.

This experiment uses the anonymized starter dataset, not the full 79-million-row production warehouse.

3. Methodology

The target label is is_declining_label: 1 represents a downward trend and 0 represents a non-downward trend. It was derived from the dataset's trend_direction field.

A Random Forest classifier with 100 trees, balanced class weights and random_state 42 was trained using metadata-only features.

Validation used a grouped client split: 25 clients for training and 7 unseen clients for testing, containing 6,163 test records.

The final feature set excluded client and content identifiers, the target and target-related fields, and historical performance fields to reduce leakage risk.

The rule-based baseline used freshness and impression tiers. Both methods were evaluated on the same held-out records.

5. Limitations and Honest Interpretation

  • The experiment used 30,000 anonymized starter records, not the full production warehouse.
  • The grouped test contained only 7 unseen clients.
  • The model's Precision@50 was lower than the baseline.
  • Metadata cannot fully represent content quality, user needs or business value.
  • A downward trend does not always mean that a page needs updating.
  • Results may not generalize to other clients or future datasets.

This is an experimental decision-support system. Further validation and expert feedback are needed before wider use.
